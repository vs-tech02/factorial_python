# Factorial Program in Python

## 📌 About the Project

This repository contains a beginner-friendly Python program that calculates the factorial of a number entered by the user.

The program uses a `for` loop to multiply the integers from `1` to the entered number and displays the calculated factorial.

## 🚀 How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the folder containing `factorial.py`.
4. Run the following command:

   ```bash
   python factorial.py
   ```

   If your system uses Python 3 through `python3`, run:

   ```bash
   python3 factorial.py
   ```

5. Enter a number when prompted.

## 🧠 What Is a Factorial?

The factorial of a non-negative integer is the product of all positive integers less than or equal to that number.

For example:

- `5! = 5 × 4 × 3 × 2 × 1 = 120`
- `3! = 3 × 2 × 1 = 6`
- `0! = 1`
